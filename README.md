## ✨ Коротко

- 🕒 **Работает сам, круглосуточно.** Включил один раз, дальше Buffy сам решает, когда копать, читать и драться, и спит до следующего дела.
- 🎮 **Всё в одном окне.** Карты, главы, алмазы, башня и ранг арены видны сразу, а журнал рассказывает простыми словами, что бот сделал.
- 📲 **Пишет в Telegram.** Выпала карта, пришёл обмен, что-то сломалось: узнаешь сразу, даже не подходя к компьютеру.
- 🛡️ **Бережёт аккаунт.** Делает паузы как живой человек, не долбит сайт повторными входами и останавливается, если сайт просит притормозить.
- 🔄 **Обновляется сам.** Новая версия ставится тихо и никогда не прерывает вечерний кубок.

## 🚀 Начать за пару минут

1. Скачай со [страницы релизов](https://github.com/Qu4dyz/MangaBuff-Miner-Bot/releases/latest) **`Buffy-Setup-….exe`** (установщик) или **`Buffy-…-portable.zip`** (если не хочешь ничего устанавливать).
2. Запусти. Windows может предупредить «Система Windows защитила ваш компьютер»: так бывает с программами без платной цифровой подписи. Нажми **Подробнее → Выполнить в любом случае**.
3. Войди в MangaBuff по почте и паролю или в один клик через **ВКонтакте, Discord, Яндекс или Google**.
4. По желанию подключи Telegram: мастер сам найдёт твой чат.
5. Включи нужные модули и нажми **«Запустить»**. Можно закрыть окно: Buffy уйдёт в трей у часов и продолжит работать.

> 💡 Buffy выходит только здесь, на [странице релизов](https://github.com/Qu4dyz/MangaBuff-Miner-Bot/releases) этого репозитория. Копии под другими названиями — не наши, и программе с доступом к твоему аккаунту лучше не доверять вслепую.

## 🧩 Что умеет Buffy

Каждый модуль включается и выключается отдельно, а большинство можно запустить вручную кнопкой прямо сейчас.

| | Модуль | Что делает |
|:-:|---|---|
| 📅 | **Ежедневные награды** | Отмечает визит, чтобы не прерывалась серия «Дней подряд», забирает награду дня и за выполненные задания |
| ⛏️ | **Шахта** | Тратит дневную энергию шахты на руду и сам покупает новую кирку и «Сильный удар» |
| 📖 | **Чтение глав** | Добирает до 10 бонусных карт в день и квест на 75 глав |
| ⚔️ | **Арена** | Собирает сильнейшую колоду, бьётся, пока дают эссенцию, открывает сундуки |
| 🏆 | **Вечерний кубок** | С 19:00 до 22:00 МСК играет кубок ход за ходом |
| 🏰 | **Башня Разлома** | Забирает награды экспедиций, сразу отправляет отряд снова и качает Штаб |
| 🏛️ | **Клуб** | Вносит кристаллы и подсказывает, когда клубу нужна твоя карта |
| 📺 | **Реклама** | Три просмотра в день, это +21 💎, смотреть ничего не нужно |
| 🎃 | **Ивенты** | Во время праздников собирает ивентовые награды, например конфеты на Хэллоуин |
| ✨ | **Перебор пробуждения** | Пробуждает выбранные карты снова и снова, пока ATK, HP и CR не дойдут до твоих минимумов |
| 🔮 | **Перековка печати** | Меняет печать выбранным картам, пока не выпадет нужная, не трогая ATK, HP и CR |

<details>
<summary><b>📖 Чтение глав подробнее</b></summary>

<br>

Новая бонусная карта становится доступна примерно раз в 45–60 минут. Buffy читает главы, пока она не выпадет, и заодно закрывает дневные 75 глав. Между главами он делает паузы, как живой читатель, иначе сайт главы не засчитает.

Если сайт перестал засчитывать главы на каком-то тайтле (например, они уже были прочитаны), Buffy переходит на другой. У новых аккаунтов сайт ставит для карт дополнительные условия: если карты не падают, Buffy заметит это и до конца дня будет читать только 75 глав, за них сайт даёт алмазы.

</details>

<details>
<summary><b>⚔️ Арена и кубок подробнее</b></summary>

<br>

Колоду Buffy собирает сам: смотрит на атаку, здоровье, печати и энергию карт. Уставшие карты (меньше 10 энергии) он временно меняет на отдохнувшие. Соперников выбирает по силе и истории боёв, ценные карты не трогает.

По желанию Buffy тратит бесплатные пробуждения на новые карты (не чаще раза в 6 часов). По умолчанию это выключено: отменить пробуждение нельзя.

В вечерний кубок он сам выбирает цель и тактику на каждом ходу. Пока идёт кубок, остальные задачи ждут.

</details>

<details>
<summary><b>🏰 Башня Разлома подробнее</b></summary>

<br>

Когда отряд возвращается, Buffy забирает алмазы и кристаллы и сразу отправляет его в самую выгодную безопасную экспедицию: перебирает все сложности и длительности и учитывает время до вечернего кубка. Лишние кристаллы вкладывает в Штаб. Один раз выбери отряд на сайте, дальше Buffy справится сам.

</details>

## ✨ Пробуждение: перебор статов и перековка печати

Отдельная страница «Пробуждение» в Buffy.

**Перебор статов.** Выбираешь одну или несколько карт плитками (с артом, рангом, номером копии и текущими статами) и ползунками ставишь минимумы ATK, HP и CR. Бот пробуждает карту, смотрит статы и, если они ниже, бесплатно снимает пробуждение и пробует снова. Тратит только энергию пробуждения, которая копится с боёв, и показывает, сколько её осталось и какой шанс выбить такие статы.

- Каждый бросок виден сразу, с печатью. Кнопка «Остановить и оставить» сохраняет карту с тем броском, что на экране: перед каждым новым броском бот ждёт 3 секунды.
- «Оставить как есть» — забрать текущий бросок у одной карты, «Изменить минимумы» и «Продолжить» — без повторного выбора карт.
- Карта, стоявшая в колоде или в отряде Башни, возвращается на место. Во время вечернего кубка перебор ждёт.
- Когда карта готова — уведомление Windows и сообщение в Telegram.

**Перековка печати.** Выбираешь пробуждённые карты и подходящие печати, бот перековывает (500 эссенции за раз), пока не выпадет одна из них, и не тратит больше заданного лимита. У каждой печати подсказка: как часто она стоит у соперников и выигрывает ли чаще, чем обещает сила колоды. Сила колоды при этом важнее любой печати.

## 🔐 Вход в аккаунт

**По почте и паролю.** Если сайт сбросит вход, Buffy незаметно войдёт снова.

**Через ВКонтакте, Discord, Яндекс или Google.** Нажми нужную кнопку: откроется обычное окно MangaBuff, войди там как в браузере, и Buffy подхватит вход. Пароль от соцсети он не видит и не хранит.

Когда сайт сбросит вход, Buffy сам повторит его в невидимом окне: соцсеть тебя помнит, так что обычно это занимает пару секунд. Окно появится, только если соцсеть попросит что-то подтвердить. Об этом Buffy напишет в Telegram.

<details>
<summary><b>Google не пускает во встроенное окно?</b></summary>

<br>

Google иногда блокирует вход внутри приложений. Тогда на странице входа MangaBuff нажми «Забыли пароль?», задай пароль для своей почты и входи в Buffy по почте и паролю.

</details>

## 📲 Telegram

Подключается в мастере первого запуска или в настройках. Buffy пишет:

- 🃏 какая карта выпала, с картинкой; свитки и редкие находки;
- 🔁 о новых обменах со ссылкой, чтобы ответить;
- 🏛️ когда клубу нужна карта из твоей коллекции;
- 🏰 📺 ⛏️ итоги башни, рекламы, шахты и арены;
- 🚨 если не получается войти, сайт долго недоступен или начался ивент.

🌙 **Ночной режим** с 23:00 до 08:00 МСК присылает всё без звука и без отчётов. 🔕 **Всегда без звука** оставляет со звуком только самое срочное.

## 🖥️ Приложение

- **Трей и автозапуск.** Закрытое окно сворачивается к часам, а Buffy может стартовать вместе с Windows.
- **Ручной запуск.** Любой модуль можно запустить кнопкой, не дожидаясь его очереди.
- **Понятный журнал.** Вместо технических логов короткие фразы вроде «Забрал награду Башни: +40 💎».
- **Автообновления.** Можно выключить в настройках.

## 🔒 Твои данные

Вход, настройки и журнал хранятся только на твоём компьютере, в `%APPDATA%\Buffy` (кнопка **«Папка с данными»** в настройках). Buffy общается только с MangaBuff, с Telegram (если подключён) и с GitHub, чтобы проверить обновления.

## 🆘 Если что-то пошло не так

1. Нажми **«Сообщить о проблеме»** в журнале или настройках и в двух словах опиши, что случилось.
2. Buffy сохранит подробный отчёт `Buffy-diagnostic.txt` и откроет папку с ним. Пароли, почта и токены в отчёте скрыты.
3. На открывшейся странице GitHub перетащи файл в сообщение и отправь.

## 🛠️ Для сервера и разработчиков

Внутри Buffy тот же бот, что умеет работать без интерфейса, например на Linux-сервере 24/7.

| Режим | Команда | Что делает |
|---|---|---|
| 🌙 Демон 24/7 | `python main.py --daemon` | Работает без остановки и спит до ближайшего события: энергии, возвращения из башни, сундука, полуночи МСК |
| ▶️ Один проход | `python main.py` | Делает полный цикл и выходит |
| 📊 Статус | `python main.py --status` | Только смотрит состояние аккаунта, ничего не трогает |
| 💜 Buffy | `python main.py --app` | Приложение для Windows (нужен `requirements-desktop.txt`) |

### Установка

```bash
git clone https://github.com/Qu4dyz/MangaBuff-Miner-Bot.git
cd MangaBuff-Miner-Bot
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt   # для Buffy: requirements-desktop.txt
```

Данные для входа можно положить в `.env` в корне проекта, иначе бот спросит их при первом запуске:

```env
MANGA_LOGIN=you@example.com
MANGA_PASSWORD=your_password
TG_TOKEN=123456:bot-token     # по желанию
TG_CHAT_ID=123456789          # по желанию
```

> На сервере работает вход по почте и паролю. Вход через соцсети требует окна Buffy.

### Служба systemd

```ini
# /etc/systemd/system/mangabuff.service
[Unit]
Description=MangaBuff bot
After=network-online.target

[Service]
User=mangabuff
WorkingDirectory=/opt/mangabuff
ExecStart=/opt/mangabuff/venv/bin/python main.py --daemon
Restart=always
RestartSec=60

[Install]
WantedBy=multi-user.target
```

```bash
sudo useradd --system --home /opt/mangabuff mangabuff
sudo chown -R mangabuff /opt/mangabuff
sudo systemctl enable --now mangabuff
```

### Устройство проекта

```
├── main.py             # точка входа: CLI, демон, Buffy
├── engine.py           # основной цикл: вход, шахта, чтение, башня, награды
├── arena.py            # арена: колода, бои, пробуждение, вечерний кубок
├── club.py             # клуб: кристаллы и запросы карт
├── http_session.py     # HTTP с TLS-отпечатком браузера и обработкой DDoS-Guard
├── tg_notifier.py      # уведомления в Telegram
├── data_management.py  # настройки, вход и сессия
├── diagnostics.py      # отчёты без паролей и токенов
├── buffy/              # приложение для Windows: окно, интерфейс, трей, обновления
└── tests/              # тесты: python -m pytest tests
```

**Зависимости:** `requests` и `curl_cffi` (сеть), `beautifulsoup4` (разбор страниц), `python-dotenv` (`.env`), а для Buffy ещё `pywebview`, `pystray` и `pillow`.
