# 🤖 MangaBuff Майнер Бот v10.2

**MangaBuff Miner** — это Python-автоматизация для игры MangaBuff с майнингом и боевой системой. Использует чистые HTTP-запросы (без браузерной автоматизации) для входа, получения ежедневных наград, выполнения ежедневных квестов, фарса битв на эссенцию и добычи руды.

## ✨ Возможности

* **🔐 Авторизация через API:** Вход через Laravel-бэкенд по email/password, извлечение CSRF-токена со страницы логина, сессия через куки (кэшируются в `session_cache.json`).
* **🎁 Ежедневная награда:** Парсит страницу `/balance` для поиска активной кнопки «Забрать» и отправляет POST на динамический эндпоинт.
* **📺 Ежедневный просмотр рекламы (3x7 💎):** Автоматически просматривает до 3 реклам в день через `POST /balance/ads` (+21 алмаз ежедневно) с соблюдением естественных пауз на длительность видео (~18–22с).
* **📖 Чтение глав манги (`/addHistory`):** Последовательное прочтение глав с реалистичными задержками (10–18с) для фарма до 10 бонусных карт в сутки, свитков заточки и закрытия квеста на 75 глав. История сохраняется в `reading_state.json`.
* **🏰 Экспедиции Башни Разлома (`/tower`):** Автоматическая проверка активной экспедиции. Если завершена — собирает награды (алмазы + тёмные кристаллы + уровни карт), отправляет отчёт в TG и сразу запускает новый 12-часовой поход (Nightmare) с текущим сохранённым отрядом.
* **⚔️ Ежедневные квесты:** Сканирование страницы `/battle` для завершённых, но не полученных квестов; безопасное получение наград на эссенцию, алмазы и свитки через API.
* **⚔️ Фарм битв:** Запуск битв через `/battle/fight/start`, переход на страницу результата, извлечение заработанной эссенции. Завершение при достижении дневного лимита (1000/день — определяется по 3 подряд битвам с 0 эссенцией).
* **⛏️ Добыча руды и авто-апгрейд:** Отправляет запросы на `/mine/hit`, автоматически проверяет и покупает улучшения кирки и «Сильный удар» в магазине.
* **💾 Сохранение сессии:** Сохраняет куки, CSRF-токен и User-Agent в `session_cache.json`; повторно использует до HTTP 419 с автоматическим перелогином.
* **🔐 Хранение учётных данных:** Сохраняет email/password локально в `user_data.json` (в открытом виде — только для локального использования).
* **🛡️ Анти-бан гуманизация:** Случайные задержки между действиями (4.5–12.2с), между битвами (10–20с), микроперерывы (35–75с каждые 10–15 битв).
* **🃏 Сохранение ценных карт:** Обнаруживает дропы карт редкости legendary/mythic в результатах битв и сохраняет их в `jackpot_cards.json` (защищены от расхода).
* **🌍 Мультиязычность:** Полная поддержка английского, русского и украинского языков.
* **🖥️ GUI & CLI режимы:** Удобный графический интерфейс CustomTkinter либо чистый консольный режим.
* **📲 Telegram-уведомления:** Асинхронный воркер без задержек и флуда, отправляющий структурированные HTML-сводки.

## 🚀 Как запустить (Из исходного кода)

1. Установите Python 3.10+.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` с Telegram-креденциалами (опционально, но рекомендуется):
   ```
   TG_TOKEN=ваш_токен_бота
   TG_CHAT_ID=ваш_chat_id
   ```
4. Варианты запуска:
   - **Обычный запуск (CLI):**
     ```bash
     python main.py
     ```
   - **Быстрая проверка статуса без выполнения действий:**
     ```bash
     python main.py --status
     ```
   - **Графический интерфейс (GUI):**
     ```bash
     python main.py --gui
     ```

## 🛠 Технологии

* **HTTP:** `requests` + `requests.Session` (постоянное хранилище куки + заголовки)
* **HTML-парсинг:** `BeautifulSoup4` + `regex` (для извлечения встроенного JSON со страницы результатов битвы)
* **GUI:** `CustomTkinter` — опциональный графический интерфейс
* **Уведомления:** HTTP API вызовы через `tg_notifier.py` (стиль `python-telegram-bot`)
* **Хранение данных:** `user_data.json` (учётные данные), `session_cache.json` (сессия), `jackpot_cards.json` (сохранённые карты)

## 📁 Ключевые файлы

| Файл | Назначение |
|------|------------|
| `main.py` | Точка входа с переключателем CLI/GUI (`USE_CLI_MODE`) |
| `engine.py` | Класс `MangaMinerBot` — вся логика фарма (логин, майнинг, битвы) |
| `gui_app.py` | Класс `App` — GUI на CustomTkinter; также содержит `run_cli_bot()` |
| `config.py` | Словарь `CONFIG` (URL-ы, CSS-селекторы), `TARGET_RARITIES` |
| `path.py` | Константы путей `BASE_DIR`, `DATA_FILE`, `SESSION_FILE` |
| `tg_notifier.py` | Функция `send_message()` — отправка уведомлений в Telegram |
| `data_management.py` | Класс `DataManager` — persistence учётных данных и сессии |
| `requirements.txt` | Зависимости Python |
| `user_data.json` | Хранит email, пароль, язык (создаётся при первом запуске) |
| `session_cache.json` | Кэш куки сессии, CSRF-токен, User-Agent |
| `jackpot_cards.json` | Сохранённые дропы карт legendary/mythic |

## ⚙️ Настройка

Отредактируйте словарь `CONFIG` в `config.py` для изменения:
- URL-ы (`login`, `game`, `mine`)
- CSS-селекторы для парсинга страницы майнинга (баланс, энергия, стоимость апгрейда)
- `TARGET_RARITIES` в `config.py` — tier'ы карт для сохранения (по умолчанию: `["legendary", "mythic"]`)
