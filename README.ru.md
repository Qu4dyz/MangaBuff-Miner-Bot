# 🤖 MangaBuff Майнер Бот v10.2

**MangaBuff Miner** — это мощный бот для автоматизации игры MangaBuff с современным графическим интерфейсом.
Полностью имитирует действия человека, поддерживает авто-покупки улучшений и работу в фоновом режиме.

![Status](https://img.shields.io/badge/Status-Inactive-gray)
![Python](https://img.shields.io/badge/Python-3.10%2B-blue)

## ✨ Возможности

* **🖥️ Современный GUI:** Темная тема, плавные анимации (CustomTkinter).
* **🌍 Мультиязычность:** Полная поддержка Русского 🇷🇺, English 🇺🇸 и Української 🇺🇦.
* **👻 Скрытый режим (Headless):** Может работать полностью невидимо, не мешая вам.
* **⚡ Умный кликер:** Использует JavaScript-клики для обхода лагов и анимаций сайта.
* **🛠️ Авто-прокачка:** Сам проверяет магазин и покупает улучшения кирки.
* **💾 Сохранение данных:** Помнит ваш логин (локально) и последний баланс.
* **⏱️ Таймер сброса:** Показывает время до сброса лимитов по МСК.

## 🚀 Как запустить (Для пользователей)

1. Скачайте файл `.exe` из раздела **Releases** (справа на странице).
2. Запустите файл.
3. Введите логин/пароль от MangaBuff (данные сохраняются только у вас на ПК в файле `user_data.json`).
4. Нажмите **Начать майнинг**.

## 💻 Запуск из исходного кода (Для разработчиков)

1. Установите Python 3.10+.
2. Установите зависимости:
   ```bash
   pip install customtkinter selenium webdriver-manager
3. Запустите скрипт:
   ```bash
   python main.pyw
