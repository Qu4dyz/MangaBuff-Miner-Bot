# 🤖 MangaBuff Майнер Бот v10.2

**MangaBuff Miner** — это Python-автоматизация для игры MangaBuff с майнингом и боевой системой. Использует чистые HTTP-запросы (без браузерной автоматизации) для входа, получения ежедневных наград, выполнения ежедневных квестов, фарса битв на эссенцию и добычи руды.

## ✨ Возможности

* **🔐 Авторизация через API:** Вход через Laravel-бэкенд по email/password, извлечение CSRF-токена со страницы логина, сессия через куки (кэшируются в `session_cache.json`).
* **🎁 Ежедневная награда:** Парсит страницу `/balance` для поиска активной кнопки «Забрать» и отправляет POST на динамический эндпоинт.
* **⚔️ Ежедневные квесты:** Однопроходное сканирование страницы `/battle` для завершённых, но не полученных квестов; получение наград через API.
* **⚔️ Фарс битв:** Запуск битв через `/battle/fight/start`, переход на страницу результата, извлечение заработанной эссенции через regex из встроенного JSON. Остановка при достижении дневного лимита (1000/день — определяется по 3 подряд битвам с 0 эссенцией).
* **⛏️ Добыча руды и авто-апгрейд:** Отправляет запросы на `/mine/hit`, автоматически проверяет и покупает улучшения кирки в магазине.
* **💾 Сохранение сессии:** Сохраняет куки, CSRF-токен и User-Agent в `session_cache.json`; повторно использует до HTTP 419 (истечение сессии) с автоматическим перелогином.
* **🔐 Хранение учётных данных:** Сохраняет email/password локально в `user_data.json` (в открытом виде — только для локального использования).
* **🛡️ Анти-бан гуманизация:** Случайные задержки между действиями (4.5–12.2с), между битвами (10–20с), микроперерывы (45–120с каждые 10–15 битв).
* **🃏 Сохранение ценных карт:** Обнаруживает дропы карт редкости legendary/mythic в результатах битв и сохраняет их в `jackpot_cards.json` (никогда не расходуются).
* **🌍 Мультиязычность (на уровне кода):** Переводы на английский, русский и украинский существуют в коде.
* **🖥️ GUI (опционально):** CustomTkinter GUI доступен — запускается с `USE_CLI_MODE = False` в `main.py`.
* **📲 Telegram-уведомления:** Отправляет лог-сообщения в Telegram-бота (настраивается через `.env`).

## 🚀 Как запустить (Из исходного кода)

1. Установите Python 3.10+.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` с Telegram-креденциалами (опционально, но рекомендуется):
   ```
   TG_TOKEN=ваш_токен_бота
   TG_CHAT_ID=ваш_chat_id
   ```
4. Запустите скрипт:
   ```bash
   python main.py
   ```
   - При первом запуске будет предложено ввести email и пароль MangaBuff (сохраняются локально в `user_data.json`).
   - По умолчанию (`USE_CLI_MODE = True`) скрипт работает в CLI-режиме: логинится (или восстанавливает сессию), получает ежедневную награду, выполняет квесты, добывает руду, апгрейдит кирку, затем входит в цикл фарса битв до достижения дневного лимита эссенции или исчерпания энергии.
   - Установите `USE_CLI_MODE = False` в `main.py` для запуска графического интерфейса CustomTkinter.

## 🛠 Технологии

* **HTTP:** `requests` + `requests.Session` (постоянное хранилище куки + заголовки)
* **HTML-парсинг:** `BeautifulSoup4` + `regex` (для извлечения встроенного JSON со страницы результатов битвы)
* **GUI:** `CustomTkinter` — опциональный графический интерфейс
* **Уведомления:** HTTP API вызовы через `tg_notifier.py` (стиль `python-telegram-bot`)
* **Хранение данных:** `user_data.json` (учётные данные), `session_cache.json` (сессия), `jackpot_cards.json` (сохранённые карты)

## 📁 Ключевые файлы

| Файл | Назначение |
|------|------------|
| `main.py` | Точка входа с переключателем CLI/GUI (`USE_CLI_MODE`) |
| `engine.py` | Класс `MangaMinerBot` — вся логика фарма (логин, майнинг, битвы) |
| `gui_app.py` | Класс `App` — GUI на CustomTkinter; также содержит `run_cli_bot()` |
| `config.py` | Словарь `CONFIG` (URL-ы, CSS-селекторы), `TARGET_RARITIES` |
| `path.py` | Константы путей `BASE_DIR`, `DATA_FILE`, `SESSION_FILE` |
| `tg_notifier.py` | Функция `send_message()` — отправка уведомлений в Telegram |
| `data_management.py` | Класс `DataManager` — persistence учётных данных и сессии |
| `requirements.txt` | Зависимости Python |
| `user_data.json` | Хранит email, пароль, язык (создаётся при первом запуске) |
| `session_cache.json` | Кэш куки сессии, CSRF-токен, User-Agent |
| `jackpot_cards.json` | Сохранённые дропы карт legendary/mythic |

## ⚙️ Настройка

Отредактируйте словарь `CONFIG` в `config.py` для изменения:
- URL-ы (`login`, `game`, `mine`)
- CSS-селекторы для парсинга страницы майнинга (баланс, энергия, стоимость апгрейда)
- `TARGET_RARITIES` в `config.py` — tier'ы карт для сохранения (по умолчанию: `["legendary", "mythic"]`)

## ⚠️ Известные ограничения

| Область | Статус |
|---------|--------|
| **Payload квестов** | Отправляет несколько кандидатных имён полей (`user_daily_quest_id`, `id`, `quest_id`, `daily_quest_id`); точное имя не подтверждено из вкладки Network |
| **Ключ эссенции в JSON** | Эссенция результата битвы извлекается через regex из встроенного JSON; имя ключа угадано (`essence`, `essence_gained`, `reward`, `gain`, `added`, `essence_added`) |
| **Определение пустой колоды** | Эвристический поиск текстовых фраз "empty deck"; хрупко к изменениям UI |
| **Обнаружение дневного лимита** | Остановка после 3 подряд битв с 0 эссенцией; может ложносрабатывать на новых/пустых колодах |
